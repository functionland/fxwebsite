Introducing the Fula S3-Compatible API

Build on the Decentralized Storage

Build your dApp using any S3-compatible client library. The Fula API follows the S3 standard, so you can use familiar tools like AWS SDK, MinIO client, or any S3 library to store and retrieve data on the decentralized Fula network — at up to 20x the speed of other decentralized storage networks like IPFS.
